1) Make a new GitHub repo, upload ALL files of this folder (including hidden .github).
2) Actions -> "Build APK" -> download artifact "VMusic-apk" -> install app-debug.apk.
Wallpapers: drop images into app/src/main/assets/wallpapers/ before building, or add them inside the app (Settings -> Look -> Wallpapers).
App icon: delete app/src/main/res/drawable/ic_launcher.xml and put your picture at app/src/main/res/drawable/ic_launcher.png
